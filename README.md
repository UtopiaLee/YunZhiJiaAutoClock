# 云之家自动打卡 Android 应用

这是一个用于云之家应用的自动打卡 Android 应用，使用无障碍服务实现自动打卡功能。

## 功能特性

- 自动识别云之家打卡界面
- 支持设置上班和下班打卡时间
- 可选择工作日（周一至周五）
- 定时自动打卡
- 打卡记录查看

## 使用方法

1. 安装应用
2. 打开应用，点击"开启无障碍服务"按钮
3. 在系统设置中启用本应用的无障碍服务
4. 设置上班和下班打卡时间
5. 选择需要打卡的工作日
6. 点击"保存设置"

## 构建说明

使用 Android Studio 打开项目：

```bash
# 在 Android Studio 中打开 YunZhiJiaAutoClock 文件夹
# 或使用命令行构建
./gradlew assembleDebug
```

## 权限说明

- 无障碍服务权限：用于自动识别和点击打卡按钮
- 前台服务权限：用于保持应用在后台运行
- 闹钟权限：用于设置定时打卡

## 注意事项

- 首次使用需要手动开启无障碍服务
- 确保云之家应用已安装
- 建议将本应用加入电池优化白名单，避免被系统杀死
